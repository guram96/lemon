# Retro Steam

Self-hosted retro game library: EmulationStation meets Steam Big Picture.
A headless server manages your ROM collection; clients on any device browse it and download games.

M1–M3 are built: first-run setup, artwork and metadata, and resumable downloads. Next is M4, launching a game. The board is [tasks.md](tasks.md). Architecture and commands are in [CLAUDE.md](CLAUDE.md).

```sh
flutter pub get
dart tool/check.dart
```
